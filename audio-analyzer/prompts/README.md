# Songsmith Audio Analyzer prompts

Prompts for the standalone **Songsmith Audio Analyzer** app (`audio-analyzer/`), which checks finished files. It is not the Songsmith Plugin Analyzer (`plugin-analyzer/`), the Reference and Result VST3 pair.

Every task has a stable **ANA-##** reference, distinct from its GitHub PR number. See [traceability rules](../../shared/prompts/README.md#prompt-identity-and-traceability). The board decides order; see the [execution policy](../../docs/songsmith-execution-policy.md). Merged prompts move to `done/`.
