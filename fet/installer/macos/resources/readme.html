Where things go

/Library/Audio/Plug-Ins/VST3/Songsmith Analog Compressor.vst3
/Library/Audio/Plug-Ins/Components/Songsmith Analog Compressor.component
/Applications/Songsmith Analog Compressor.app

Your presets stay in ~/Library/Songsmith Studio/Songsmith Analog Compressor/Presets. The installer never touches them, or Songsmith EQ.

Why macOS warned you about this installer

The installer isn't signed or notarised by Apple, so Gatekeeper blocks it the first time. To open it: try to open it once, then go to System Settings → Privacy & Security and click Open Anyway.

Uninstalling

Quit your DAW, then run fet/installer/macos/uninstall.sh from the source on GitHub (tonygward/audio-plugins), or paste this into Terminal:

sudo rm -rf "/Library/Audio/Plug-Ins/VST3/Songsmith Analog Compressor.vst3" \
  "/Library/Audio/Plug-Ins/Components/Songsmith Analog Compressor.component" \
  "/Applications/Songsmith Analog Compressor.app"
for id in vst3 au app; do sudo pkgutil --forget com.songsmithstudio.songsmithanalogcompressor.$id; done

Your presets are kept either way.
