# Task 15: Scale the whole curve

**Branch:** `roadmap/15-scale-curve`

## Goal
One control that scales every band's gain together, so users can dial the whole EQ in or out.

## Requirements
- A new host parameter `gain_scale`, ranging from -100% to +200% with a default of 100%. Negative values invert the curve.
- Apply it inside the DSP as a multiplier on each band's effective gain in dB, **without changing the stored band gain parameters**. Users can automate the scale, and the per-band values stay intact.
- Only bands with gain are affected (Bell, shelves). Cuts and notches are unchanged.
- It must go through the existing gain smoothing so moving the scale is click-free.
- **Display:** the curve and node positions show the *scaled* result. Show the scale value in the top bar. Double-click it to reset to 100%.
- If Task 08's presets exist, the scale is stored in presets.
- Sessions saved before this change load at 100%.

## Tests
- 0% gives flat response for bell and shelf bands, while cuts and notches stay active.
- 50% on a +12 dB bell measures +6 dB.
- -100% inverts it (-12 dB).
- 100% is bit-identical to `main`.
- Rapid automation of the scale stays finite and smooth.
