This installs the Songsmith Studio plugins @SUITE_VERSION@ for every user on this Mac:

  • Songsmith EQ @EQ_VERSION@: shape the tone of a track
  • Songsmith Analog Compressor @FET_VERSION@: even out the level and add analogue warmth
  • Songsmith Maximiser @MAX_VERSION@: make a finished mix louder without clipping

Each plugin comes as a VST3 plugin (for most recording software), an Audio Unit (for Logic Pro and GarageBand) and a standalone app that runs on its own. Everything is selected. Click Customize on the Installation Type page to leave out a plugin.

Quit your recording software before you continue. Software that's running keeps using the old version until you restart it.

Installed a plugin with its own installer before? This replaces it, so there's still only one copy. Your sessions and presets carry over.
